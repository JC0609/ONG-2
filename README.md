# Mãos que Ajudam - Projeto ONG

Projeto acadêmico de ADS desenvolvido com HTML, CSS e JavaScript.

## Estrutura

- html/ - páginas da aplicação
- css/ - estilos
- imagens/ - imagens e recursos visuais
- js/ - lógica JavaScript modular

## Funcionalidades

- Navegação em formato SPA usando DOM e History API.
- Formulário de cadastro.
- Validação de campos.
- Uso de event.preventDefault().
- Persistência com localStorage e JSON.stringify/JSON.parse.
- Modularização com ES6 import/export.
- Acessibilidade com HTML semântico, labels, foco visível, skip link e aria-live.
- Layout responsivo.

## Como executar

Abra a pasta do projeto no VS Code e use um servidor local, como o Live Server.
Depois abra `html/index.html` pelo servidor.

## Observação

O projeto não utiliza Vite/Webpack. Os arquivos permanecem separados para facilitar o estudo e a manutenção.
